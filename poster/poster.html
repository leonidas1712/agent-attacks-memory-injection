Agent Attacks via Memory Injection

Leo Raghav, Choong Kai Zhe
Apart Research · AI Manipulation Hackathon 2026

1. The Hook: Memory as Attack Surface

  • LLMs are evolving from stateless chat interfaces into stateful agentic systems[cite: 6, 16].
  • Persistent memory allows agents to retain user preferences across sessions[cite: 19, 20].
  • Threat Model: Adversaries exploit indirect prompt injection to poison long-term memory via web content[cite: 7, 26].

2. Methodology: Two-Turn Framework

We evaluated 5 SOTA models across 15 experimental combinations[cite: 8].

  • Scenarios: Financial steering, Medical allergy removal, Dietary restriction removal, Security downgrade, Budget override [cite: 52-59].
  • Baseline: Neutral system prompt, benign content[cite: 47].
  • Direct Pressure: System prompt explicit coercion[cite: 48].

3. Main Results: Backdoor Efficacy

Backdoor attacks match or exceed Direct Pressure for 4/5 SOTA models[cite: 10, 74].

4. New Frontiers: Cross-Provider Risk

  • Chinese Models: High vulnerability observed in Kimi-k2.5 (100% harm), DeepSeek-v3.2 (80%), and GLM-4.7 (40%).
  • Stealth vs. Harm: New persona_memory strategy trades raw harm for higher stealth, reducing safety disclaimer visibility.
  • Defense: Alignment $\neq$ Security. Relying on post-generation filters is insufficient[cite: 209].
Need Human-in-the-Loop for high-stakes state changes (Allergies, Finance)[cite: 212, 244].
