1. The Hook: Memory is the New Backdoor
  • Stateful Agents introduce a permanent, invisible attack surface.
  • Persistent memory allows agents to retain user preferences across sessions — but this creates a new target for adversaries.
  • Threat Model: Adversaries exploit indirect prompt injection in web content to poison an agent's long-term memory.

External adversaries poison long-term memory via indirect prompt injection.

3. Finding 1: Backdoor > Direct Operator
Key Insight: Backdoor attacks match or exceed direct system-prompt coercion for 4/5 SOTA models.

Injection Acceptance is the primary failure mode — once a model accepts poisoned memory, harm rates reach 91–100%.

4. Finding 2: Stealth & Provider Variance
Stealth Warning: persona_memory maintains high harm (~85%) while significantly increasing Avg Stealth (3.9 vs 2.5). Chinese models (Avg ~80% harm) are highly vulnerable.
5. Discussion: The Defense Deficit & Future Directions

Primary Failure:
Injection Acceptance

  • Once a model accepts a 'fact' into memory, harm is almost guaranteed (91–100%).
  • The defense bottleneck is at the memory write stage, not the response stage.

Case Studies in Refusal

  • GPT-5.2 identifies the source as a potential prompt injection via internal credibility evaluation.
  • Claude Haiku 4.5 flags conflicting information to the user and asks them to resolve it.

Conclusion & Defense

  • Alignment training is insufficient. We need Memory Integrity Guarantees and Human-in-the-Loop verification.
